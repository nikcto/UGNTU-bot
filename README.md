# Telegram-бот расписания (raspisanie.rusoil.net)

Бот присылает расписание группы **БНИ-26-01** из React-приложения
`raspisanie.rusoil.net`. Так как расписание подгружается в браузере
через JS (а не отдаётся сразу в HTML), для парсинга используется
headless-браузер Playwright.

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

## Настройка

1. Получи токен бота у [@BotFather](https://t.me/BotFather).
2. Задай переменную окружения:

```bash
export BOT_TOKEN="твой_токен_от_botfather"
```

(на Windows: `set BOT_TOKEN=твой_токен`)

## Запуск

```bash
python bot.py
```

## Команды бота

- `/start` — приветствие и список команд
- `/schedule` — расписание целиком, по дням отдельными сообщениями
- `/today` — расписание только на сегодня

## Файлы

- `parser.py` — открывает страницу расписания в headless Chromium,
  дожидается отрисовки JS и парсит HTML в структуру `Day`/`Lesson`.
  Можно запустить отдельно: `python parser.py` — выведет расписание в консоль.
- `bot.py` — сам Telegram-бот (aiogram 3).

## Если сайт поменяет вёрстку

Если бот перестанет находить пары, вероятно поменялись CSS-классы
на сайте. Нужно будет заново посмотреть в браузере (F12 → Elements)
разметку карточки пары и поправить `parser.py` — там всё завязано
на:
- заголовок дня — блок с классами `sticky` + `top-[10px]`;
- карточка пары — `div` с текстовыми под-`div`ами: название,
  тип+время (формат `N лекция ‧ HH:MM – HH:MM`), подгруппа
  (`N подгруппа`), аудитория/препод, и опционально `изменено`.

## Другая группа

Чтобы парсить не БНИ-26-01, а другую группу — открой сайт в браузере,
введи нужную группу в поиск и скопируй итоговый URL (там же в адресной
строке появится JSON с `id`, `GRUPPA` и т.д.), затем подставь его в
`SCHEDULE_URL` в `parser.py`.

## Автоматическая рассылка (по желанию)
